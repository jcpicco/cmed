# Release Notes - MedCenter Manager v1.4.0

Version 1.4.0 marks the official rebranding of the platform from **CMED** to **MedCenter Manager**. This update focuses on visual identity consistency and a series of Quality of Life (QOL) enhancements to the user interface to streamline daily operations.

---

# Backend

## Modifications

* **Model attribute changes:** Patient.phone and Patient.birthDate are now nullable fields. 

---

# Frontend

## Rebranding: From CMED to MedCenter Manager

The application has undergone a full identity migration to reflect the new project name.

* **Global Naming Update:** Replaced all UI instances, titles, and labels of "CMED" with **MedCenter Manager**.
* **Asset Refresh:** Updated logos, favicons, and branding elements across the login suite and main application headers.
* **Document Headers:** Automatically generated PDF headers and export titles now display the new naming convention.

## Quality of Life (QOL) Improvements

### Interface Refinement
Several UI components have been polished for better usability and a more modern aesthetic:

* **Layout Optimization:** Adjusted paddings and margins in the dashboard and patient detail views to improve information density on smaller screens.
* **Breadcrumb Navigation:** Refined navigation path visibility to help users orient themselves better within deep-nested patient records.
