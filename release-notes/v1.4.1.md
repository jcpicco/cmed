# Release Notes - MedCenter Manager v1.4.1

Version 1.4.1 introduces advanced PDF template generation with precise coordinate mapping and incorporates new standardized medical consent forms, significantly streamlining administrative and legal documentation processes.

---

# Frontend

## Advanced PDF Template Engine

* **Integración de `pdf-lib`:** The application now supports loading and populating native PDF documents, complementing the legacy `jsPDF` generation. This enables pixel-perfect data placement over pre-designed PDF templates.
* **Mapeo de Coordenadas:** Added a flexible field mapping system (`PdfTemplateDefinition`) within `PdfManagerService`. This system precisely places text and boolean checkmarks ("X") at specific `x` and `y` coordinates across multiple pages.
* **Soporte de Casillas de Verificación (Checkboxes):** Implemented logic to correctly process "select" input types, drawing marks in the exact coordinates corresponding to affirmative ("Sí") or negative ("No") answers for clinical history questions.

## New Medical Consent Templates

Added complete definitions and integrated PDF assets for the following standardized forms:

* **Documento de Protección de Datos (GDPR):** (`gdpr_es.pdf`).
* **Consentimiento Infusión de Vitamina C:** (`vitc_infusion_es.pdf`). Includes newly mapped clinical history fields (Alteración de la función renal o litiasis, Alteración de la función cardíaca, Diabetes, Deficiencia de G6PD, Hipomagnesemia o hipoclacemia, Hemocromatosis, Hiperoxaluria).
* **Consentimiento Básico sin Fármacos:** (`non_pharma_es.pdf`). Includes mappings for patient background and allergies.
* **Consentimiento Autohemotransfusión con Ozono:** (`ozone_autohemo_es.pdf`). Includes specific clinical checks like Favismo and Hipertiroidismo.

## Interfaz de Usuario

* **Patient Detail Component:** Updated the patient detail view and PDF template selector to seamlessly integrate the new `pdf-lib` generation flow, allowing staff to quickly generate and download filled consent forms.

---

# Technical & Tooling

* **Scripts de Extracción:** Added utility scripts (`extract_checks.js`, `extract_json.js`) to assist developers in extracting PDF coordinate data and bounding boxes for faster template creation.
* **Dependencias:** Added `pdf-lib` and `pdf.js-extract` to the project to handle advanced PDF parsing and manipulation.
